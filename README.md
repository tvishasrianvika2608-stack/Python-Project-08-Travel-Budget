# Project 8: Multi-Currency Travel Budget Analysis

## Problem Description
This project analyses travel expenses in different foreign currencies. It converts expenses into Indian Rupees using the supplied exchange rates, calculates conversion fees, compares total spending against the planned budget, and identifies the largest expense category.

## Programming Language
Python

## Concepts Used
- Variables and data types
- Lists
- For loops
- Conditional statements (if, elif, else)
- Arithmetic operators
- User input and output

## Files Included
- `Question_08_Travel_Budget.py` – Python source code
- `Screenshots/` – Code and output screenshots

## How to Run
1. Download the Python file.
2. Open it using Python or VS Code.
3. Run the program.
4. Enter the travel budget and expense details.
5. Enter the currency amounts and exchange rates.
6. View the travel budget report.

## Conclusion
The program converts foreign currency expenses into Indian Rupees, calculates conversion fees, checks whether the planned expenses are within the budget, and identifies the largest expense category.
